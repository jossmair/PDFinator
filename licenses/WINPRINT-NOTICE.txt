PDFinator vendor changes: the optional PDFium downloader build script and its
network/verification-only build dependencies are removed. Default features are
empty and explicitly enabling the unsupported PDFium path produces a compilation
error. Only the native Windows.Data.Pdf / XPS spooler backend is used. No print
backend or OS wrapper implementation is changed.

The inline source-font layout in src/ui/inline.rs is adapted from PdfCraft 0.9
edit_text_ui.rs, copyright (c) 2026 ArtCraft Team and PdfCraft contributors,
under MIT OR Apache-2.0. The application interface and vector pictograms are
original PDFinator creations.
